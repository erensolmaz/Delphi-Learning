## ✨ Features

- Explains basic VCL components and their purpose
- Beginner-friendly demonstration app
- Single-form Windows application

## 🚀 Getting Started

1. Open `Project1.dproj` in **Embarcadero Delphi** (RAD Studio).
2. Build & run (`F9`), or launch the prebuilt `Win32/Debug/Project1.exe`.
